### Expected Impact

- **Zero code changes expected** — all are patch/minor bumps with backward-compatible changes
- **Tests should pass** — same results as Phase 7 (4/7 suites, 108/112 tests)
- **App should launch** — no runtime changes to Electron, React, or Express

## Scope

**In scope**:
- Update all listed dev dependencies to latest versions
- Run tests to verify no regressions
- Test app launch
- Update openspec config

**Out of scope**:
- Express 4→5 upgrade (separate phase)
- UUID 8→14 upgrade (separate phase)
- Any code changes

## Success Criteria

1. `npm install` completes without errors or ELSPROBLEMS
2. `npm test` passes (same results as Phase 7)
3. `npm start` launches the app correctly
4. No new lint errors introduced

## Risks

- ESLint 10 may have rule changes that flag existing code
- Jest 30.4 may have minor API changes in test helpers
- CopyWebpackPlugin 14 may have config format changes (already tested in Phase 1)

## Migration Steps

1. Update package.json with new versions (exact, no ^ or ~)
2. Run `npm install` to update lock file
3. Run `npm test` to verify no regressions
4. Run `npm start` to verify app launches
5. Update openspec/config.yaml to mark Phase 8 complete
